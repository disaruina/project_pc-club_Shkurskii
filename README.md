## Собственный проект

Тема проекта: ПК клуб

Главный класс: Club

Почему этот объект нужен программе:
чтобы хранить данные о месте или о компьютере 

Какие данные хранит объект:

- Seatnumber отвечает за место в пк клубе
- Zone отвечает за зону в пк клубе випка или обычное или буткемп
- Money_an_hour денег в час за место
- Busy свободно ли место или нет

Какие значения задаются через конструктор:
Seatnumber int номер места, Zone string тариф, Money_an_hour int стоимость часа, Busy bool статус места

Какие значения можно задавать автоматически:
статус Busy сразу устанавливается в false

## Практическая работа №2

### Поведение главного класса

Пришлось поменять половину проекта и саму задумку его для выполнения этой лабораторной 

Метод 1: `public int Price()`
Что делает: возвращает стоимость часа в зависимости от тарифа

Метод 2: `public void Start()`
Что делает: проверка хватает ли денег на то количество часов которое захотел пользователь

Метод 3: `public void AddHours(int DopHours)`
Что возвращает: добавление часов пользователю и проверка на добавление отрицательного значения 

Почему эти действия относятся именно к этому классу:
Потому что все эти действия относятся к конкретному компьютеру: проверка его тарифа, списание баланса, занятость места и добавление часов. Удобнее и безопаснее, когда каждый компьютер сам следит за своими деньгами и временем, а не меняется извне как попало

### ПР №3. Инкапсуляция собственного класса

Класс и его назначение:
класс Club описывает игровое место в пк клубе хранит его номер тариф баланс часы и занятость

Какие данные защищены и почему:
защищены баланс часы номер места тариф и занятость чтобы снаружи нельзя было вручную накрутить деньги или занять комп без оплаты
Какие свойства имеют private set:
Seatnumber Zone Balance Hours и Busy

Какое свойство использует закрытое поле:
все сделаны через автосвойства get private set отдельные закрытые поля вручную не прописывал

Что проверяют конструктор и методы:
конструктор проверяет чтобы баланс не был отрицательным часы и номер места были больше нуля а тариф совпадал с нужными метод Start проверяет свободен ли комп и хватает ли денег метод AddHours проверяет что добавляемые часы больше нул
